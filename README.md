# AI and Image Processing - CAP 631

These files contain the practical codes developed with my CAP 631 teacher for **AI and Image Processing**.  
The work focuses on tasks such as **image classification, detection, recognition, analysis, and manipulation** — all aimed at transforming raw pixels into meaningful, workable information that can be understood and used by machine learning models.

## 📌 Highlights
- Image classification and recognition
- Object detection and analysis
- Preprocessing and manipulation of images
- Converting visual data into features for ML models

## 🎯 Goal
To bridge the gap between raw image data and machine learning by applying computer vision techniques that make images interpretable for AI systems.
